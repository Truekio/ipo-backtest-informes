# ipo-backtest-informes

Informes del backtest de la estrategia de rupturas en OPV recientes.

- `index.html`: página de entrada (se publica con GitHub Pages).
- `informes/`: un HTML por tanda de pruebas, generado con `tools/make_report.py` del proyecto.

Para añadir un informe: copiar el `.html` a `informes/` y añadir su enlace en `index.html`.
